A standalone interactive preview of the Staxil Desk retail workspace. All records are fictional, generated from the project's seed function. No database, credentials, environment files, uploads or customer exports are included.

## Explore

Dashboard, searchable catalog, sample customers, sales, reports and simulated point of sale. Add products, adjust quantities and record a sample payment. Changes last only until the page reloads or Reset demo is selected. CSV exports contain fictional demo records only.

This static demo has no authentication or security boundary. Do not enter private information. Payments are simulations. AI, email, integrations and server administration are not connected. The original local application remains separate and unchanged.

## GitHub Pages

Upload the contents of this folder to the root of a public repository. Under Settings → Pages choose Deploy from a branch, main, /(root), then Save. All asset paths are relative, including support for /staxil-desk/ hosting. No package installation or build is required.

For local preview, serve this folder with a static HTTP server; JavaScript modules require HTTP rather than opening index.html directly.
