# Staxil Desk · Retail workspace demo

A little less admin. A lot more retail.

**[View the project portfolio](https://victor-staxil-portfolio.fluffylamb36.chatgpt.site)** · **[Launch the interactive demo](https://victor-staxil-portfolio.fluffylamb36.chatgpt.site/demo/)**

A personal retail software project by **victortripura03-cloud**. This repository contains a standalone demonstration using fictional records. The complete application's repository, server code, database and uploaded files remain private.

## Try the workflow

1. Browse the dashboard and searchable product catalog.
2. Open Point of sale, add products and adjust quantities.
3. Record a simulated payment, then find it in Sales.
4. Review sample reporting and export fictional sales as CSV.

Changes stay in browser memory and reset on reload. No sign-in or payment information is required. Do not enter private information. No actual payments, AI calls, emails or external integrations run in this demo.

## About the complete project

The local application uses JavaScript, Node.js and SQLite. Its workflows include register sessions and cash audits, role-based access, outlet stock and transfers, purchase orders, CSV imports, customizable taxes and receipt templates. Optional AI and email adapters require configured providers. Payment methods are manual labels; configured integration entries do not imply a live connection.

The public preview presents a smaller set of workflows and has no connection to the private application's records.

## Run this demo locally

Serve this directory using a static HTTP server, then open its local URL. JavaScript modules require HTTP; opening index.html as a local file is insufficient. No dependency installation or build is needed.
